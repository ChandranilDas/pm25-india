# PM2.5 over India (course project 3, beginner version)

Brief: docs/PROJECT.md. Simplest version of ../pm25-india: 6 plain scripts
(step1_...py to step6_...py), no helper modules, no tests. Keep it beginner-friendly.

- Run with `conda run -n pm25 python stepN_....py`, in order.
- data/raw links to ../pm25-india/data/raw (never modify). Results in results/stepN/.
- Docs: one file per step in docs/steps/ (Status, Purpose, Idea in plain words, How it
  works, Outputs, How to run, Decisions, Problems met, Results, Open issues), plus
  journal.md (dated, decisions in bold), glossary.md and 00_overview.md. Keep them current.
- Local git only; no Claude attribution in commits.
